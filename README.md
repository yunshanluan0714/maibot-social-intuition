# `maibot-social-intuition`（`github.yunshanluan0714.social-intuition`） (v1.0.0) — 熟人社交直觉套件

平时零存在感静默感知、**常态 0 Prompt 注入、零主动刷屏**，只在熟人自己冒泡聊天时触发 3 项极其自然的人情味直觉：

1. **「后续呢？」生活近况静默追问**：
   - 群友随口提到明天面试、下午拔牙、寄修显卡、周末看展等有明确后续的事，后台静默记下；等事件过去后下次他再冒泡，顺口自然问一句“后来咋样了”。
2. **跨月「既视感」翻旧账**：
   - 结合 `llm.embed` 向量相似度与字符相似度，捕捉“某位熟人今天又发了跟两周/数月前如出一辙的吐槽”，经小模型确认后顺口调侃一句“这话怎么听着这么耳熟”。
3. **「失踪老友回归」静默感应**：
   - 本地静默统计老群友活跃度（至少累计 10 条发言以上），彻底潜水 15 天以上某天突然冒泡时，顺手轻接一句“稀客啊”。

## 防打扰设计
- **单回合互斥仲裁**：同一条消息最多只向模型注入 1 条一次性线索（优先级 `生活近况 > 久别重逢 > 既视感`），绝不堆叠；
- **深夜免打扰**：默认 `01:00–08:00` 只静默记录不触发注入；
- **启动历史回填**：首次加载自动异步只读导入近 60 天群消息（零 Embedding 成本），上线首日即具备失踪天数与历史吐槽底座；
- **严格单群隔离**：按 `group_id`（私聊隔离为 `private:<user_id>`）独立存库，绝不跨群串台。
